# วิธีใช้สกิล storybook-3d-selfdrawn-story (คลิปนิทาน ฉาก 3D ตัวละครวาดเอง)

ทำคลิปนิทานแนวตั้ง 9:16 ยาวประมาณ 60 วินาที จากไฟล์เสียงพากย์อย่างเดียว
- ฉากเป็น 3D แต่ดูเหมือนภาพวาด 2D สีสด สว่าง มีเส้นขอบหมึก
- ตัวละครตัวเล็กป้อม หัวขาวบุบนิด ๆ เส้นขอบหนาแบบการ์ตูน แขนขาเส้นเล็ก
- **สกิลวาดตัวละครให้เองทั้งหมด ไม่ต้องสร้างภาพใน Flow**
- มีซับทีละคำ เสียงประกอบ เพลงประกอบที่แต่งใหม่ และปก

**ได้ไฟล์:** มีเพลง / ไม่มีเพลง / ปก (ตัวอย่าง: "สะพานสองหมู่บ้าน")

## ติดตั้ง (ทำครั้งเดียว)
แตกไฟล์สกิล เปิดแอป Claude ไปที่แท็บ Code เลือกโฟลเดอร์สกิลนี้เป็นโปรเจกต์ แล้วพิมพ์ "ติดตั้งสกิล"
(สกิลจะเช็กเองว่าเครื่องมีอะไรแล้ว ขาดอะไรติดตั้งให้อัตโนมัติ)
ใช้บนมือถือ/iPad ได้ แต่เรนเดอร์ช้ากว่าบนคอม

## สิ่งที่ต้องใช้
- ไฟล์เสียงพากย์จาก ElevenLabs ยาว 50-70 วินาที
- เวลาที่ใช้: ประมาณ 1.5-2 ชั่วโมงต่อคลิป (ส่วนใหญ่เป็นเวลาเรนเดอร์ราว 40 นาที)

## วิธีใช้
1. พิมพ์ "คิดบทนิทานสั้น เรื่อง [หัวข้อ] ยาว 60 วินาที" จะได้บท (script.txt)
2. นำบทไปทำเสียงใน ElevenLabs
3. ส่งไฟล์เสียงแล้วพิมพ์ "ทำคลิปด้วยเสียงนี้"
   - สกิลจะวาดตัวละคร สร้างฉาก และเรนเดอร์ให้จนจบ
   - ถ้าเสียงเผลออ่านคำที่ไม่อยู่ในบท บอกได้เลยว่าให้ตัดคำไหนออก

## เทคนิค
- **อยากเปลี่ยนหน้าตาตัวละคร:** บอกเป็นคำ เช่น "ช่างไม้ใส่หมวกฟาง ผ้ากันเปื้อนสีน้ำตาล มีหนวด"
- **ตัวละครสูงไป กลมไป หรือเส้นหนาไป:** บอกได้ สกิลจะส่งภาพเรียงตัวละครให้ดูก่อนเรนเดอร์ทั้งคลิป
- **อยากให้มีช่วงเงียบก่อนเฉลย:** บอกว่า "เว้นเงียบ 1 วิ ก่อนประโยค [ประโยค]"
- **เปลี่ยนสถานที่:** ฉากพร้อมใช้คือหมู่บ้านสองฝั่งแม่น้ำ สะพาน ป้ายนับเลข โต๊ะเขียนแบบ และเรือพาย ฉากอื่นจะสร้างเพิ่มให้ในสไตล์เดียวกัน
- **แก้เฉพาะช่วง:** บอกวินาทีมา เช่น "ช่วง 0:40 ป้ายโดนบัง" จะแก้และเรนเดอร์เฉพาะช่วงนั้น

ปล. ตัวละคร เรื่อง และฉากจะคิดใหม่ทุกครั้ง ไม่ลอกจากคลิปอ้างอิงของคนอื่น
